
DailyNews 🚀

Fully Automated AI-Powered News to YouTube Shorts Pipeline

DailyNews is an automated content generation system that transforms news and interesting stories from Medium Daily Edition into engaging YouTube Shorts.

The entire pipeline is designed to run locally using self-hosted AI models, from content extraction and script generation to video rendering and automatic YouTube publishing.

🎯 Target Channel: @DailyNews777_

✨ Features
📰 Automated News Scraping – Collects the latest stories from Medium Daily Edition.
🧠 Local AI Processing – Uses locally hosted LLMs to analyze articles and generate engaging scripts.
✍️ AI Scriptwriting – Converts longer articles into short, engaging news scripts.
🎙️ AI Voice Generation – Generates natural-sounding voiceovers locally.
🎬 Automated Video Creation – Produces vertical 9:16 videos optimized for YouTube Shorts.
🖼️ Visual Generation – Creates or selects visuals to accompany each story.
📤 Automatic YouTube Upload – Publishes finished videos directly to YouTube.
🔄 Fully Automated Pipeline – Designed to operate without manual video editing.

🧠 Local AI

The project is designed around locally running AI models to minimize reliance on paid cloud-based AI APIs.

Potential integrations include:

Ollama – Local LLM inference.
Whisper – Speech recognition.
Piper / XTTS – AI text-to-speech.
FFmpeg – Video processing and rendering.

🛠️ Project Goals

The main goal is to build a fully autonomous AI-powered news publishing system that:

Finds interesting stories automatically.
Understands and summarizes their content.
Generates original short-form scripts.
Produces complete videos using local AI.
Publishes content automatically to YouTube.
⚠️ Disclaimer

This project is intended for educational and personal automation purposes.

Content sourced from Medium should be transformed into original summaries and commentary, with appropriate attribution and links to original authors. Scraping and redistribution must comply with applicable copyright laws and Medium's terms.

Automated YouTube publishing should also comply with YouTube's policies, including its rules on reused and repetitive content.
